# ☕ Core Java

Ye repository meri **Core Java** seekhne ki journey ka record hai. Yahan main jo bhi concepts seekh raha hun, unke programs, practice questions aur notes daalta rehta hun.

## 🎯 Goal

Java ko basics se lekar advanced topics tak strongly samajhna aur regularly practice karke apni coding skills improve karna.

## ⚙️ Requirements

- Java JDK 8 ya usse upar
- Koi bhi IDE: IntelliJ IDEA, Eclipse ya VS Code

## ▶️ Program Kaise Run Karein

```bash
# Repository clone karein
git clone https://github.com/<your-username>/core-java.git

# Folder me jayein
cd core-java

# Program compile karein
javac FileName.java

# Program run karein
java FileName
```
